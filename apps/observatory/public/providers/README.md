# Provider marks

The Codex provider uses OpenAI's Blossom mark and the Claude provider uses Claude's
starburst, beside the product name. SVG geometry is bundled from T3 Code's
[provider icons](https://github.com/pingdotgg/t3code/blob/main/apps/web/src/components/Icons.tsx).
OpenAI and Anthropic retain ownership of their marks; these identify recorded
providers and do not imply endorsement. No remote asset request is made by the UI. The source license is retained in
[T3-LICENSE.txt](T3-LICENSE.txt).

The repository mark comes from GitHub's [Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg) (MIT); its notice is retained in [OCTICONS-LICENSE.txt](OCTICONS-LICENSE.txt).

Primary brand resources: [OpenAI](https://openai.com/brand/) and
[Anthropic media assets](https://www.anthropic.com/news).
