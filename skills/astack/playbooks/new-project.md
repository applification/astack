# New project

1. **research**: Read existing guidance and establish product, users, fixed choices, open decisions and the smallest end-to-end milestone. Model-role setup is separate.
2. **design**: Compare open decisions against product constraints with [architect](../../architect/SKILL.md) when useful. Show trade-offs before committing; use project-selected platform guidance.
3. **implementation**: Follow [first milestone guidance](../references/new-project.md). Build the smallest useful path and record actual commands in existing project instructions. Add no mandatory layout, control CLI or framework.
4. **review**: Use [code-review](../../code-review/SKILL.md), [testing](../../testing/SKILL.md) and [verify](../../verify/SKILL.md) to run the real artifact and a meaningful failure where applicable. Return observed results and exact gaps.
5. **lead**: Resolve findings and finish kept changes through [pr](../../pr/SKILL.md).

The lead owns integration. Resolve model roles through [orchestration](../references/orchestration.md); inherited roles may run directly. Preserve the task’s authority and report omitted steps with reasons.
