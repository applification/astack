# App control

1. **research**: Use [app-control](../../app-control/SKILL.md) to inspect the running product and existing drivers. Identify the concrete missing capability.
2. **implementation**: Repair or add that project-owned capability. Keep a feature map only when it helps find user paths.
3. **review**: Use [code-review](../../code-review/SKILL.md) to challenge the diff and [verify](../../verify/SKILL.md) to drive and observe one real path and clean up owned resources. Return findings and proof gaps.
4. **lead**: Resolve findings and finish authorized changes through [pr](../../pr/SKILL.md).

The lead owns integration. Resolve model roles through [orchestration](../references/orchestration.md); inherited roles may run directly. Preserve the task’s authority and report omitted steps with reasons.
