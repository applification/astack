# Performance

1. **research**: Use [performance](../../performance/SKILL.md) to choose the metric, record comparable conditions and measure the baseline.
2. **design**: Trace the measured bottleneck and choose one supported cause to change. Do not substitute a microbenchmark for the user path.
3. **implementation**: Make the bounded improvement using the project’s selected tools.
4. **review**: Use [code-review](../../code-review/SKILL.md) to challenge the diff and [verify](../../verify/SKILL.md) to compare under the same conditions. Return the result, variability and remaining limits.
5. **lead**: Resolve findings and finish authorized delivery through [pr](../../pr/SKILL.md).

The lead owns integration. Resolve model roles through [orchestration](../references/orchestration.md); inherited roles may run directly. Preserve the task’s authority and report omitted steps with reasons.
