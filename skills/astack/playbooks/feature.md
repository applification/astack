# Feature

For agent environment improvements, [correct](../../correct/SKILL.md) owns the scope throughout this sequence: deterministic project tooling, configuration and checks, preserving application source and behavior. Return application defects as separate findings.

1. **research**: For environment work, use [correct](../../correct/SKILL.md) to inspect failure evidence and existing check commands. For application work, read affected paths and consumers and name the requested behavior and material cases with [implement](../../implement/SKILL.md).
2. **design**: Choose enforcement in existing project tools for environment work. For a consequential interface, state or ownership choice, apply [architect](../../architect/SKILL.md) within the selected scope. Use [domain-modeling](../../domain-modeling/SKILL.md) when concepts need sharpening. Compare useful alternatives; record a reason when this step is unnecessary.
3. **implementation**: Use [correct](../../correct/SKILL.md) for environment changes or [implement](../../implement/SKILL.md) for application changes. Run the fast checks before dependent work. For a requested hosting transition, use [cloud-transition](../../cloud-transition/SKILL.md) with the selected host and recovery checks.
4. **review**: Apply [code-review](../../code-review/SKILL.md) and [verify](../../verify/SKILL.md) to assess the integrated result against intent and quality. For environment work, verify bad-case rejection, valid-case acceptance and unchanged application source. Return findings and proof gaps.
5. **lead**: Resolve findings, recheck affected behavior and finish authorized delivery through [pr](../../pr/SKILL.md).

The lead owns integration. Resolve model roles through [orchestration](../references/orchestration.md); inherited roles may run directly. Preserve the task’s authority and report omitted steps with reasons.
