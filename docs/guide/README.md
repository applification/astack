# The astack guide

Install the Applification plugin, establish a project loop an agent can run, then describe the outcome you want and how to check it. astack routes the work through focused skills and applicable principles. You can also invoke any skill directly.

1. [Establish the project loop](01-project-setup.md). Create a new product or integrate and upgrade an existing one.
2. [Give astack work](02-give-it-work.md). Prompt by outcome, understand routing and use focused skills directly.
3. [Understand and shape the change](03-understand-and-design.md). Trace behavior and history, settle boundaries and resolve product choices.
4. [Verify and maintain the loop](04-verification.md). Drive real behavior, retain evidence and repair stale control guidance.
5. [Steer and resume](05-steer-and-resume.md). Use principle names, carry decisions forward and review the completed work.

Start with a small real task. Each chapter then serves as a reference for later work. The [skill directory](../../skills/) owns the reusable instructions; your project's `.astack/project.md` owns its actual runtime and proof commands.

The guide structure is informed by [pstack's guide](https://github.com/cursor/plugins/tree/4e5b1cf2ccb0ea3716f08c8ee0a5856b5ab93536/pstack/docs/guide), adapted to astack's project setup, focused skills and Codex installation.
