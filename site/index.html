MODEL SETUP

Choose the models.
Save choices with the project.

$applification:setup-astack discovers available models and asks about budget/preferences. It saves confirmed research, design, implementation and review choices in this project's committed .astack/models.json.

Claude and Codex through T3

T3's live provider catalog supplies valid models and reasoning options. Pinned targets run through a host that exposes those exact model IDs and options, including cross-provider work in T3. The lead stays responsible for the task.

Setup configures contributions. It does not change the main chat's model or scaffold a product.

Start without configuration

Missing configuration and omitted roles inherit the current session. An unavailable saved pin stops its contribution with a reported gap.

Persistent modes, parent-model selection and scheduling belong to the host.

FEEDBACK

Principles guide judgment.
Project checks enforce rules.

Use the project's compiler, lint, tests and runtime checks. Repeated agent corrections should become demonstrated safeguards in that project.

Project enforcement

$applification:correct investigates repeated mistakes and changes the owning architecture, type, lint or behavior check. Prove that the bad case fails and a valid case passes. Record the enforcing command in existing project guidance.

Model setup does not invent lint rules. astack ships no application presets.

astack package checks

bun install --frozen-lockfile
bun run check

Checks reject malformed metadata, missing assets, broken skill/playbook links, and invalid model targets or options. Bun is this repository's authoring tool.

PROOF

Run the real thing.
Keep gaps visible.

Proof names a revision, environment, action and observed result. Package validation and saved model choices do not prove an agent delivered the requested outcome.

Use the project's actual check commands and running-product tools. For a pinned role, inspect the host's returned provider/model identity. The lead resolves findings and verifies the integrated result; read-only work ends with its answer. Retain concise evidence in the PR when publication is part of the assignment.
