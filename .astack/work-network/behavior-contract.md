# Captured work network

An Observatory owner can explore agent work as a relationship network and inspect the capture supporting each link. Work story remains the default chronological reading view; Graph replaces the fixed-column diagram with the network direction accepted in the interactive graph experiment.

The event log remains authoritative. This change derives a view, without adding graph persistence or changing frozen evaluation evidence.

## Design and checks

Pen is skipped: the user's accepted running SVG network experiment supplies the visual direction for this iteration. Storybook is selected for missing capture, retries, result states, filters, layouts and keyboard interaction. Synthetic stories establish presentation behavior; the separate local Convex query establishes the real adapter and permission boundary.

Use circles and typed arrows, with a details pane and neighbor navigation. Force is the initial graph layout; community coloring is calculated from visible undirected connectivity and does not establish agent roles. Layered layout is an alternative arrangement, not a prescribed workflow. Overview is compact; expansion is local and reversible. Raw activity events stay independent: repeated command signatures and timestamp proximity do not establish call/result pairing.

Activity is metadata only (title/kind/tool/failure/timing/source reference), limited to a prefix of 48 events per readable turn and 192 activity previews overall, within the existing shared 256 KiB capture budget. Current run summaries retain trusted conversation identity and capture revision. Full traces remain the path to omitted content and nested delegation.

No production deployment, collector upgrade, graph database, inferred dependency analysis or quality score is included. Community resolution and layout are experimental presentation choices, available for comparison.

Dense expansion is capped at 360 visible nodes, retaining conversations, contributions, result observations, turns and declarations before optional detail. A display-limit notice explains the omission; selection still inspects the full bounded projection. Labels remain readable when fitting the graph and avoid overlaps; full names stay in accessible node labels and the inspector.
